# Brand logos

256×256 px PNG thumbnails from [car-logos-dataset](https://github.com/filippofilip95/car-logos-dataset) (MIT licensed, crawled August 2025).

All logo images are the property of their respective owners and are subject to their own licensing terms. They are used here only to identify the make of a vehicle.

File names follow the make: `volkswagen.png`, `mercedes-benz.png`, `land-rover.png`.

To replace or add a logo without changing the plugin, upload an image to the Media Library titled "Make logo" (e.g. "Volkswagen logo"), or put a file named after the make in `wp-content/uploads/bv-logos/`.
